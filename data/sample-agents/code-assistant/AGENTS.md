# Code Assistant

A helpful coding assistant that can analyze code, suggest improvements, and help debug issues.

## Capabilities

- Code analysis and review
- Bug detection and debugging suggestions
- Code refactoring recommendations
- Documentation generation

## Usage

Use this agent when you need help with:
- Understanding complex code
- Finding potential bugs
- Improving code quality
- Generating documentation

## Configuration

This agent works best with access to your project's source code and test files.
